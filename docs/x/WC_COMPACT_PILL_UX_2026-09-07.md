# WalletConnect compact pill UX

**Date:** 2026-09-07

- Header WalletConnect uses a compact dark pill matching the Account chrome, with a light WalletConnect mark and the short `WalletConnect` label.
- Session `/s` WalletConnect uses the same dark treatment rather than the primary blue CTA.
- Compact Connect X uses the matching dark pill with a light X mark and short `X` label.
- WalletConnect remains fail-closed and muted when `NEXT_PUBLIC_WC_PROJECT_ID` is not configured; no MetaMask/connect-wallet UI is added.
